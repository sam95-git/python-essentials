## Learning Approach

Each topic follows:
```
Learn → Document → Practice → Interview Preparation → Revise
```

### topic.md

Contains concepts, explanations, examples, and important notes.

### interview-prep.md

Contains interview questions, output-based questions, common traps, and quick revision notes.

### examples.py

Contains runnable Python examples for the topic.

## Goal

Build a strong understanding of Python, improve problem-solving skills, prepare for Python interviews, and build practical Python projects.
